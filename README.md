# 진주 문화재 야행 행사 안내·신청 웹페이지

## 실행 방법
1. 압축을 해제합니다.
2. `index.html`을 크롬 또는 엣지 브라우저에서 엽니다.
3. 상단 또는 메인 사전등록 버튼을 누르면 `registration.html` 신청 페이지로 이동합니다.

## 폴더 구조
- `index.html` : 행사 메인 페이지
- `registration.html` : 사전등록 페이지
- `css/style.css` : 메인 페이지 스타일
- `css/registration.css` : 신청 페이지 스타일
- `js/main.js` : 메뉴, 팝업, 날짜별 일정 기능
- `js/registration.js` : 신청 폼 데모 기능
- `assets/jinju-night-poster.png` : 사용자가 제공한 포스터 이미지

## 구현 기능
- 모바일 반응형 레이아웃
- 전체 일정 / 전체 프로그램 팝업
- 날짜 탭을 통한 일정 변경
- 사전등록 버튼과 별도 신청 페이지 연결
- 이름, 연락처, 이메일, 날짜, 인원, 관심 프로그램 입력

## 안내
제공된 2022년 포스터 이미지를 디자인 참고 및 메인 비주얼로 활용했습니다. 화면에 표시된 2026년 행사 날짜, 프로그램, 장소 운영 정보는 웹 제작 실습을 위한 가상 예시이며 실제 행사 일정이 아닙니다. 신청 폼은 화면상 완료 메시지만 보여주며 데이터 저장이나 실제 접수는 하지 않습니다. 실제 운영 시에는 주최 측 확정 정보와 서버·데이터베이스 연동이 필요합니다.
